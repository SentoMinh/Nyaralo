# Frontend Dokumentáció – Balatoni Nyaraló Foglalási Rendszer

## Áttekintés

A frontend egy modern, reszponzív webalkalmazás, amely lehetővé teszi a vendégek számára a balatoni nyaraló adatainak megtekintését, a szabad időszakok naptárának böngészését, valamint foglalási kérelem leadását. Az adminisztrátorok külön oldalon kezelhetik a beérkező foglalásokat (státusz és fizetési állapot módosítása).

A technológiai stack:

- **HTML5** + **Tailwind CSS** (CDN)
- **Vanilla JavaScript** (nincs framework)
- **Lucide Icons**
- **date-fns** (opcionális, betöltve)
- Egyedi CSS (`css/style.css`)
- Backend API kommunikáció (`fetch`)
